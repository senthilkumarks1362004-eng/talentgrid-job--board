# TalentGrid - Advanced Job Board

Production-ready job portal with real-world filtering logic.

**Live:** https://senthilkumarks1362004-eng.github.io/talentgrid-job-board/

## Features
- 🔍 Instant search across title/company/tags
- 🎯 Multi-filter: Role + Location + Type + Salary (AND/OR logic)
- 🔖 Bookmark system with localStorage
- 📄 Pagination (6/page), Sort by Recent/Salary
- 💼 24 jobs, detail drawer, apply modal with validation
- 📱 Fully responsive

## Stack
Tailwind CSS, Vanilla JS ES6+, HTML5 — No frameworks

## Why this is hard
Handles complex state management, empty states, and performance without React — shows advanced JS skills.
